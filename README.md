# Carmelo Moschella eLearning Portfolio

## Install in the existing GitHub Pages repository

1. Copy `index.html`, the `assets` folder and the `resume` folder into the root of `elearning-portfolio`.
2. Keep the existing folder `Brisbane City Council - Special Events` in the same root.
3. Commit and push the changes.
4. GitHub Pages will deploy automatically.

## Required edits before publishing

Open `index.html` and replace:
- `YOUR_EMAIL@example.com`
- `https://www.linkedin.com/in/YOUR-LINKEDIN/`

The Storyline launch button expects this existing path:
`Brisbane City Council - Special Events/story.html`

Additional Storyline modules can be added as sibling folders and linked from new project cards.
