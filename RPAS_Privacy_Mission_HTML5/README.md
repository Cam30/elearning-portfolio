# RPAS Privacy Mission

A self-contained HTML5 learning app for GitHub Pages. No build tools, server, LMS or external JavaScript libraries are required.

## Run locally

Open `index.html` in a modern browser. For the most reliable iframe and download behaviour, serve the folder with any local static web server.

## Publish to GitHub Pages

1. Upload the entire contents of this folder to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the branch containing the files and `/ (root)`.
5. Save, then open the published Pages URL.

Do not upload only `index.html`. The `activities`, `assets`, and `resources` folders are required.

## Learning record

Role choice, mission completion and reflections are stored in browser `localStorage`. Nothing is transmitted. Clearing browser site data resets progress.

## Assessment boundary

This is formative practice only. XP, levels and badges are motivational feedback and do not certify competence.
