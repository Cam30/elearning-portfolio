# Medicinal Cannabis Regulation & Compliance — Module 2

An eLearning module covering jurisdiction-specific requirements for pharmacists and prescribers accessing medicinal cannabis products in Australia.

## How to enable GitHub Pages

1. Push this repository to GitHub
2. Go to **Settings → Pages**
3. Set Source to **Deploy from a branch → main → / (root)**
4. Save — your live URL will appear within a minute
