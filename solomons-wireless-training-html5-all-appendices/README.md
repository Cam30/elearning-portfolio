# Solomon Islands Wireless Network Field Academy

## Upload to GitHub Pages

1. Open your GitHub repository.
2. Upload the **contents** of the `solomons-wireless-training-html5` folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the branch containing the files and the `/ (root)` folder, then save.

The live entry file is `index.html`. Do not upload the enclosing ZIP file as the website.

## Assessment behaviour

- Thirteen practice challenges provide feedback and Field XP.
- Appendix A explains how to select the correct site procedure and reinforces the pre-site tool control.
- Five Appendix B image-led pages cover Hockey Stick, 10-foot Stay Mast, and 20-, 30-, and 40-foot Telescopic Mast installation.
- Four additional image-led pages cover TIA/EIA-568 cable termination, PTP 600 LPU installation, PMP/CSM surge suppression and PTP 600 mast installation.
- Field XP does not contribute to competency.
- The summative assessment contains 10 questions.
- Competency requires all 10 answers to be correct, equal to 100%.
- Progress is stored in the learner's browser only.
- This package does not send a score to an LMS.

## Source basis

The content was designed from the supplied Solomon Islands Government wireless network installation/support manual and CBO subcontractor HSSE checklist. The operational manual remains the source of truth.
